# Animal Sounds — iOS 3.1 Home Screen Installation Instructions

1. Open **Safari** on your iPad.
2. Visit the **Animal Sounds generator**:
   https://skylerdufour429.github.io/com.smartbabyapps.animalsounds/
3. If you are installing the App Store version, open the **App Store**.
4. Search for **Animal Sounds**.
5. Select **Animal Sounds** from the search results.
6. Wait for the app to download and install.
7. Open **Animal Sounds** from the Home Screen.
8. To add the web version to your Home Screen, return to the Animal Sounds page in Safari.
9. Tap the **Share** button.
10. Select **Add to Home Screen**.
11. Enter **Animal Sounds** as the app name, if needed.
12. Tap **Add**.
13. Return to the Home Screen.
14. Tap the **Animal Sounds** icon to launch the app.
